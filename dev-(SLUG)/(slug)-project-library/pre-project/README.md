# pre-project

The three pre-project files for a new application with no context: `project-brief.md`, `scoping-ideas.md` and `constraints-and-notes.md`. Step 11 places them here, blank, from `C:\pdlf\pdlf-library\templates-local\pre-project\`. David fills them in before Step 12.

An application that already has context does not use them: Step 12 reads its existing documents instead.
