# project-template

Skeleton for starting a new project. Copy `dev-(SLUG)/(slug)-project-library/` into a new
`dev-{slug}/{slug}-project-library/` folder and fill in every placeholder marker.

**Not itself a live project** — its `AGENTS.md`, `opencode.json`, and other config files are
templates to be copied and customized, not configuration that applies to this folder directly.

See `project-template-config.yaml` for the exact current state, including a real bug found
and fixed on 2026-08-13 (a hardcoded reference to a specific real project in `opencode.json`,
which every future copy would have inherited).
